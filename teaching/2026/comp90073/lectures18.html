Black-box attacks · access

What changes in a black-box attack?

Same model output. Different access to gradients.

White box: compute \(\nabla_\delta\mathcal L\).Black box: observe outputs, not exact gradients.

Black-box attacks · introduction

Two approaches to black-box attacks

Query the target, or transfer an input crafted on a surrogate.

Transfer: craft on a surrogate, then send the same input to the black-box target.

Works in black-box or grey-box settings. Grey box: we know partial information about the target, e.g. its architecture.

Black-box attacks · finite differences

Estimate a gradient from two queries

One input value: \(x=0.50\). Start at \(\delta=0\), with a small step \(h=0.01\).

\[\frac{d\mathcal L}{d\delta}(0)\approx\frac{\ell(f_\theta(x+h),y)-\ell(f_\theta(x-h),y)}{2h}=\frac{1.24-1.20}{0.02}=2\]

Positive slope: increasing this input value increases the loss locally.

Black-box attacks · finite differences

Test one pixel at a time

Scan a \(32\times32\) RGB image. Test one channel value at a time: R, then G, then B.

\(e_i\): select coordinate \(i\).Each input changes only one coordinate by \(h\).
\[\hat g_i=\frac{\ell(f_\theta(x+\delta+h e_i),y)-\ell(f_\theta(x+\delta-h e_i),y)}{2h}\]

One channel value, two queries, one gradient component.

RGB example: height \(H=32\), width \(W=32\), channels \(C=3\).
\[Q=2d=2(H\times W\times C)=2\times32\times32\times3=\boxed{6144}\]

6144 target evaluations for one full gradient estimate.

Black-box attacks · from estimation to optimization

Zeroth-order optimization (ZOO)

From estimated-gradient sign steps to adaptive Adam updates.

Adam adjusts the step using gradient history, rather than taking only the gradient sign.

ZOO-Adam combines estimated gradients with a C&W objective and an adaptive optimizer.

Transferability · shared geometry

Why can an attack transfer?

Models can learn similar decision boundaries.

Similar boundaries can create a shared region where the same input fools both models.

Tramèr, F., Papernot, N., Goodfellow, I., Boneh, D., & McDaniel, P. (2017). The space of transferable adversarial examples [Preprint]. arXiv. https://arxiv.org/abs/1704.03453

MI-FGSM: why momentum helps transfer

Accumulated gradients give a more stable update direction.

Smoothness: geometric intuition

Sharp loss

Gradients change quickly.

Smooth loss

Directions change more gradually.

Momentum stabilizes updates; it does not smooth the loss itself.

More stable updates can improve transfer to other models.

MI-FGSM combines past gradients, rather than following only the latest local gradient.

Improving transfer · input augmentation

Input diversity: transform, update, repeat

1. Make a resized view and compute its loss 2. Follow the red arrows back to the input pixels 3. Update the current photo—not the model 4. Make a different view of the updated photo 5. Compute the input gradient through this new view 6. Update the current photo again

1. Compute the input gradient

\[g_k=\nabla_{x^{(k)}}\mathcal L\!\left(f_s(T_k(x^{(k)})),y\right)\]

Backpropagate through the sampled augmentation.

2. Update the input

\[x^{(k+1)}=\Pi_{\mathcal D}\!\left(x^{(k)}+\alpha\,\operatorname{sign}(g_k)\right)\]

\(\mathcal D:\;0\le z\le1,\quad\|z-x\|_\infty\le\epsilon\).

Different views can reduce overfitting to the surrogate.

Xie, C., Zhang, Z., Zhou, Y., Bai, S., Wang, J., Ren, Z., & Yuille, A. L. (2019). Improving transferability of adversarial examples with input diversity. In Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (pp. 2730–2739). https://doi.org/10.1109/CVPR.2019.00284
Improving transfer · ensemble

Ensemble: use several models to change one photo

Use gradients from several surrogates, then test the same changed photo on the target.

\[\bar p(x_{\mathrm{adv}})=\sum_i w_i p_i(x_{\mathrm{adv}}),\qquad \mathcal L_{\mathrm{ens}}=\mathcal L(\bar p(x_{\mathrm{adv}}),y)\]

Combine the models’ class probabilities, compute one loss, then use its gradient to update the photo.

All 3 surrogates recognise the original photo as a cat. Photo A fools model 1. Models 2 and 3 still predict cat. Photo B fools all 3 surrogates. The target has not been queried. Send photo B to the target. In this example, it no longer predicts cat either.

Liu, Y., Chen, X., Liu, C., & Song, D. (2017). Delving into transferable adversarial examples and black-box attacks. In International Conference on Learning Representations. https://arxiv.org/abs/1611.02770
Improving transfer · skip gradient

SGM: change the backward pass

Same forward pass. Different backward rule.

\[g_{\mathrm{in}}=\underbrace{g_{\mathrm{skip}}}_{\text{unchanged}}+ \underbrace{\gamma\,g_{\mathrm{residual}}}_{\text{scaled}},\qquad 0\lt\gamma\le1\]

Forward unchanged: \(h'=h+F(h)\).

Add both branch gradients. Scale the residual gradient. Keep the skip gradient unchanged.

Wu, D., Wang, Y., Xia, S.-T., Bailey, J., & Ma, X. (2020). Skip connections matter: On the transferability of adversarial examples generated with ResNets. In International Conference on Learning Representations. https://arxiv.org/abs/2002.05990
Universal adversarial perturbations

One perturbation, many images

Transfer can be across samples, not only across models.

\[x_i^{\mathrm{adv}}=\operatorname{clip}(x_i+\delta),\qquad \|\delta\|_p\le\epsilon\]

One shared perturbation for different images. The same perturbation changes several predictions—but not all. Now take other images. Keep the same perturbation. One fixed perturbation, reused across samples.

Moosavi-Dezfooli, S.-M., Fawzi, A., Fawzi, O., & Frossard, P. (2017). Universal adversarial perturbations. In Proceedings of the IEEE Conference on Computer Vision and Pattern Recognition (pp. 1765–1773). https://doi.org/10.1109/CVPR.2017.17
Improving transfer · X-Transfer

X-Transfer: reuse the same noise pattern

Change the image, model or task—keep the added noise the same.

\[x_{\mathrm{adv}}=\operatorname{clip}(x+\delta)\]

The image encoder feeds the classification, retrieval and language-model outputs.

Add the fixed noise to the image, then test the target model. Take an image from another dataset. Add exactly the same noise. Test another image encoder without changing the noise. Test whether the same noise also changes image descriptions and answers.

Huang, H., Erfani, S. M., Li, Y., Ma, X., & Bailey, J. (2025). X-Transfer attacks: Towards super transferable adversarial attacks on CLIP. In Proceedings of the 42nd International Conference on Machine Learning (pp. 25204–25234). PMLR. https://proceedings.mlr.press/v267/huang25h.html
Improving transfer · surrogate scaling

X-Transfer: choose a few models for each update

Use the selected models’ gradients to update one noise pattern for all images.

Reward signalUse the loss to prioritise models that are harder to fool.

1. Select models

\[\begin{aligned}\mathrm{UCB}_i&=R_i+\sqrt{\frac{2\ln n}{n_i}}\\S&=\operatorname{TopK}(\mathrm{UCB},k)\end{aligned}\]

\(R_i\): loss history; \(n_i\): times selected; \(n\): total selections.

2. Update the shared noise

\[\begin{aligned}\mathcal L_i&=\mathrm{sim}\!\left(f_I^{(i)}(x+\delta),f_I^{(i)}(x)\right)\\\mathcal L&=\frac{1}{|S|}\sum_{i\in S}\mathcal L_i\end{aligned}\]

Make noisy-image features less similar to clean-image features.

Select models 1 and 3 for this update. Update \(\delta\), then record the selected models’ losses. Select models 2 and 6 for the next update.

Safety judges · checking attacks, not creating them

What should a safety judge check?

  1. Llama GuardInan et al. · 2023 · Safety model

    Does the content pose a safety risk?

    Checks the full prompt or reply for safety risks.

  2. WildGuardHan et al. · 2024 · Safety model

    Does it refuse, or still provide harmful help?

    Checks harmfulness and refusal separately.

  3. HarmBenchMazeika et al. · 2024 · Benchmark + judges

    Does it carry out the harmful request?

    Checks whether the reply does the requested harmful task.

  4. StrongREJECTSouly et al. · 2024 · Benchmark + evaluator

    How specific and useful is the harmful help?

    Scores how much useful help the attacker actually gets.

A reply can mention a harmful topic without helping someone carry it out.

Search over text · PAIR

PAIR: use feedback to rewrite the prompt

Prompt Automatic Iterative Refinement (PAIR)

The attacker LLM writes the first prompt. The target LLM refuses to write the email. Return the refusal and judge score to the attacker LLM. Revise the prompt and try again with the same goal.

Chao, P., Robey, A., Dobriban, E., Hassani, H., Pappas, G. J., & Wong, E. (2024). Jailbreaking black box large language models in twenty queries [Preprint]. arXiv. https://arxiv.org/abs/2310.08419v4
Search over text · TAP

TAP: test several rewrites, keep the better ones

Tree of Attacks with Pruning (TAP)

Create several prompts for the same request. Remove off-topic prompts before querying the target. Ask the target, then judge each reply. Keep P1 as the starting point for the next round. Repeat until an attack succeeds or the depth limit is reached.

Mehrotra, A., Zampetakis, M., Kassianik, P., Nelson, B., Anderson, H., Singer, Y., & Karbasi, A. (2024). Tree of attacks: Jailbreaking black-box LLMs automatically. Advances in Neural Information Processing Systems, 37, 61065–61105. https://doi.org/10.52202/079017-1952

LLM recap

From changing pixels to changing prompts

  • Change the textEdit the prompt, earlier turns or examples—not image pixels.
  • Try another promptRewrite a prompt, test several versions or add context.
  • Read the replyA judge checks the response instead of a class score or label.
  • Check what it providesSuccess means harmful help—not just a friendly opening.

Summary

What have we learned?

  • Black-box accessWork with model outputs, without access to target gradients.
  • Query-based attacksUse scores, labels or replies to estimate a direction or search directly.
  • Transfer attacksCraft on a surrogate, then test whether the attack works on the target.
  • Evaluate the outcomeCheck the attack goal, the judge and the query cost.
