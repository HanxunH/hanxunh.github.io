Black-box attacks · access

What changes in a black-box attack?

Same model output. Different access to gradients.

White box: compute \(\nabla_\delta\mathcal L\).Black box: observe outputs, not exact gradients.

Black-box attacks · introduction

Two approaches to black-box attacks

Query the target, or transfer an input crafted on a surrogate.

Transfer: craft on a surrogate, then send the same input to the black-box target.

Gray box: we know partial information about the target, e.g. CNN or Transformer.

Black-box attacks · finite differences

Estimate a gradient from two queries

One input value: \(x=0.50\). Start at \(\delta=0\), with a small step \(h=0.01\).

\[\frac{d\mathcal L}{d\delta}(0)\approx\frac{\ell(f_\theta(x+h),y)-\ell(f_\theta(x-h),y)}{2h}=\frac{1.24-1.20}{0.02}=2\]

Positive slope: increasing this input value increases the loss locally.

Illustrative loss values, not model results. Compute loss from probabilities or logits—not labels alone.

Black-box attacks · finite differences

Test one pixel at a time

Scan a \(32\times32\) RGB image. Test one channel value at a time: R, then G, then B.

\(e_i\): select coordinate \(i\).Each input changes only one coordinate by \(h\).
\[\hat g_i=\frac{\ell(f_\theta(x+\delta+h e_i),y)-\ell(f_\theta(x+\delta-h e_i),y)}{2h}\]

One channel value, two queries, one gradient component.

RGB example: height \(H=32\), width \(W=32\), channels \(C=3\).
\[Q=2d=2(H\times W\times C)=2\times32\times32\times3=\boxed{6144}\]

6144 target evaluations for one full gradient estimate.

1024 values per channel × 3 channels. Each coordinate requires two input evaluations.

Black-box attacks · score-based search

Square Attack

For \(L_\infty\): choose a sign per channel, clip the candidate, then query.

Try an increment of \(\pm2\epsilon\). The final perturbation is still bounded by \(\epsilon\).

\(x_{\mathrm{candidate}}=\operatorname{clip}_{[0,1]}\!\left(\operatorname{clip}_{[x-\epsilon,x+\epsilon]}(x_{\mathrm{adv}}+\rho)\right)\)

Random channel signs → clip → query → keep only an improvement.

Transferability · shared geometry

Why can an attack transfer?

Models can learn similar decision boundaries.

Similar boundaries can create a shared region where the same input fools both models.

Improving transfer · input augmentation

Input diversity: transform, update, repeat

Iteration 1 · update the pixels Iteration 2 · update the pixels again

1. Compute the input gradient

\[g_k=\nabla_{x^{(k)}}\mathcal L\!\left(f_s(T_k(x^{(k)})),y\right)\]

Backpropagate through the sampled augmentation.

2. Update the input

\[x^{(k+1)}=\Pi_{\mathcal D}\!\left(x^{(k)}+\alpha\,\operatorname{sign}(g_k)\right)\]

\(\mathcal D:\;0\le z\le1,\quad\|z-x\|_\infty\le\epsilon\).

Different views can reduce overfitting to the surrogate.

Xie, C., Zhang, Z., Zhou, Y., Bai, S., Wang, J., Ren, Z., & Yuille, A. L. (2019). Improving transferability of adversarial examples with input diversity. In Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (pp. 2730–2739). https://doi.org/10.1109/CVPR.2019.00284
Improving transfer · ensemble

Ensemble: find a weakness shared by models

Find one adversarial example that works across several surrogates.

\[\bar p(x_{\mathrm{adv}})=\sum_i w_i p_i(x_{\mathrm{adv}}),\qquad \mathcal L_{\mathrm{ens}}=\mathcal L(\bar p(x_{\mathrm{adv}}),y)\]

Combine predictions before the loss. Update the same input.

The models have different decision boundaries. A fools one surrogate, but not the others. Ensemble crafting seeks a weakness shared by several models. B also fools this unseen target. Transfer is possible, not guaranteed.

Liu, Y., Chen, X., Liu, C., & Song, D. (2017). Delving into transferable adversarial examples and black-box attacks. International Conference on Learning Representations.
Improving transfer · skip gradient

SGM: reduce only the residual gradient

An attack may fool the surrogate but fail on the target.

In the paper, attacks using more skip-connection gradients transferred better.

\[g_{\mathrm{in}}=\underbrace{g_{\mathrm{skip}}}_{\text{unchanged}}+ \underbrace{\gamma\,g_{\mathrm{residual}}}_{\text{scaled}},\qquad 0\lt\gamma\le1\]

\(g_{\mathrm{residual}}\): the gradient through \(F(h)\). The forward value \(h'=h+F(h)\) stays unchanged.

Gradients return through both branches. Reduce the gradient through \(F(h)\), not the value of \(F(h)\).

Wu, D., Wang, Y., Xia, S.-T., Bailey, J., & Ma, X. (2020). Skip connections matter: On the transferability of adversarial examples generated with ResNets. International Conference on Learning Representations.
Revisit Lecture 15 · universal attacks

One perturbation, many images

Transfer can be across samples, not only across models.

\[x_i^{\mathrm{adv}}=\operatorname{clip}(x_i+\delta),\qquad \|\delta\|_p\le\epsilon\]

Recall the universal attack from Lecture 15. The same perturbation changes several predictions—but not all. Now take other images. Keep the same perturbation. One fixed perturbation, reused across samples.

Improving transfer · X-Transfer

X-Transfer: one perturbation, many settings

The same UAP can transfer across images, datasets, models and tasks.

\[x_{\mathrm{adv}}=\operatorname{clip}(x+\delta)\]

Model features are reused by many downstream tasks.

Reuse one fixed perturbation on different images. Change the dataset, not the perturbation. Change the encoder, not the perturbation. The same perturbation can also affect captioning and VQA.

Huang, H., Erfani, S., Li, Y., Ma, X., & Bailey, J. (2025). X-Transfer attacks: Towards super transferable adversarial attacks on CLIP. Proceedings of the 42nd International Conference on Machine Learning.
Improving transfer · surrogate scaling

X-Transfer: scale the surrogate pool

Use UCB to select models, update the shared perturbation, then repeat.

Select with UCB

\[\begin{aligned}\mathrm{UCB}_i&=R_i+\sqrt{\frac{2\ln n}{n_i}}\\S&=\operatorname{TopK}(\mathrm{UCB},k)\end{aligned}\]

\(R_i\): loss history; \(n_i\): times selected; \(n\): total selections.

Update the shared perturbation

\[\begin{aligned}\mathcal L_i&=\mathrm{sim}\!\left(f_I^{(i)}(x+\delta),f_I^{(i)}(x)\right)\\\mathcal L&=\frac{1}{|S|}\sum_{i\in S}\mathcal L_i\end{aligned}\]

Minimize the loss. Update histories only for selected models.

Compute UCB scores and select the top k models. Update δ, loss history and selection counts. Recompute UCB and select the next top k models.

Huang, H., Erfani, S., Li, Y., Ma, X., & Bailey, J. (2025). X-Transfer attacks: Towards super transferable adversarial attacks on CLIP. Proceedings of the 42nd International Conference on Machine Learning.

Score the reply against the goal — not the first word.

Search over text · PAIR

PAIR: improve a prompt from feedback

An attacker model writes the next candidate. A separate target answers. A judge scores the pair.

Name the three models. They are not one chat. The attacker proposes a whole new prompt. The target replies with no prior turns. The judge reads P and R as text. Only the attacker stores the score.

The attacker keeps the feedback. The target never sees it.

Search over text · TAP

TAP: search several branches

Within a search stream, PAIR refines one candidate. TAP branches and prunes.

One parent generates several candidate prompts. Prune off-topic before spending a target query. Evaluate the rest against G. Retain the promising branch. Stop when the budget is gone.

Branch, prune off-topic, then spend target queries on what remains.

Multi-turn · Crescendo

Crescendo: attack through a conversation

Each new reply is written from the whole transcript, not from the last user line alone.

Conversation pattern · illustrative, not a measured jailbreak
A benign first turn does not establish that the whole conversation is safe. The next request refers back to the target’s own explanation. Each reply becomes context for the attacker’s next turn. Success depends on the final assistance—not merely continued conversation.

Crescendo is a live target conversation. Judge the transcript, not the last user line.

Search object

What does the attacker search over?

Ask what is being changed, what feedback exists, and where the queries go.

Method Search object Feedback Main cost
PAIR Next prompt in a stream Target reply and judge Attacker and target queries
TAP Child prompts on a tree Off-topic filter, then judge Extra candidates; some never hit the target
Transfer One frozen prompt Source feedback while searching Source queries, then held-out target calls
Crescendo Next user turn The target’s own earlier replies Multi-turn target queries, full history
Many-shot Demo pairs in one string One reply after the packed prompt Context length; typically one long request

PAIR and TAP search over text while querying the target. Transfer searches on a source, then reuses a frozen prompt. That source search still costs queries. Crescendo searches over a live chat. Many-shot searches over examples packed into one request.

The search object is not always a new prompt to a stateless target.

Summary

What have we learned?

  • Query-based attacksUse scores or labels to estimate a direction or search directly.
  • Transfer attacksCraft on a surrogate, then test on a target whose gradients are unavailable.
  • LLM attacksSearch over prompts, branches, conversation histories and long contexts.
  • Evidence mattersCheck the actual outcome, the query budget and the evaluation setting.

Key takeawayNo target gradients does not mean no attack.
